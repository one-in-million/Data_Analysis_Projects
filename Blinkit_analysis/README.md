# 🛒 Blinkit Sales Analysis with Python

This project focuses on analyzing Blinkit sales data using Python libraries. The goal is to understand customer preferences, product performance, and store-level characteristics that drive revenue growth.

---

## 📌 Project Overview

Blinkit is a popular quick-commerce platform that sells a variety of products. Understanding sales patterns and customer preferences can help optimize product stocking, pricing, and store operations.

In this project, we:
- Performed **data cleaning and preprocessing**  
- Conducted **exploratory data analysis (EDA)**  
- Applied **visualization techniques** for better insights  
- Derived **business-focused conclusions** to support decision-making  

---

## 🛠️ Technologies Used

- **Python**  
- **Pandas** – Data manipulation  
- **NumPy** – Numerical computations  
- **Matplotlib & Seaborn** – Data visualization  

---

## 📊 Key Insights

### Conclusion from the Analysis

1. **Top-performing products and stores** contribute significantly to revenue — focusing on them can improve overall sales.  
2. Customers **prefer Fruits, Vegetables, and Snack items**, whereas **Seafood and Breakfast items are least preferred**.  
3. **Store characteristics** (type, size, location) strongly affect sales performance.  
4. **Low-fat products** are more popular and should be stocked more than regular ones.  
5. **Store age is not directly related** to performance — older stores do not necessarily perform better or worse.
