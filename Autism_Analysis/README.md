# 🧩 Autism Analysis with Python

This project focuses on analyzing Autism Spectrum Disorder (ASD) screening data using Python libraries. The goal is to identify key factors that may contribute to ASD likelihood and provide insights through data exploration, visualization, and statistical analysis.

---

## 📌 Project Overview

Autism Spectrum Disorder (ASD) is a developmental disorder that affects communication, behavior, and social interaction. Early screening and detection are crucial for better outcomes.

In this project, we:
- Performed **data cleaning and preprocessing**  
- Conducted **exploratory data analysis (EDA)**  
- Applied **statistical and visualization techniques**  
- Derived insights into factors affecting ASD likelihood  

---

## 🛠️ Technologies Used

- **Python**  
- **Pandas** – Data manipulation  
- **NumPy** – Numerical computations  
- **Matplotlib & Seaborn** – Data visualization  
- **Scikit-learn** – Model building & evaluation  

---

## 📊 Key Insights

### Conclusion from the Analysis

1. **Screening Scores** – Individuals with higher **Total Screening Scores** are more likely to be classified as having Autism Spectrum Disorder (ASD).  
2. **Age** – ASD likelihood does not strongly depend on age in this dataset.  
3. **Gender** – There is a slight imbalance (more males screened), but ASD presence is **not limited to one gender**.  
4. **Relation** – When the screening form is filled by **self**, scores tend to be higher compared to those filled by **parents/others**. This suggests that **self-reporting may capture symptoms more effectively**.  
5. **Jaundice History** – Some variations were observed, but **it is not a strong predictor of ASD** in this dataset.
